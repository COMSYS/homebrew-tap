# COMSYS Tap

## How do I install these formulae?

`brew install comsys/tap/<formula>`

Or `brew tap comsys/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "comsys/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
